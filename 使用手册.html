🖥️ new-acad 使用手册

版本 v1.3.3 ｜ 让 AI 直接帮你操作 AutoCAD / Civil 3D

一句话说明：在 Civil 3D 里选中图元 → 打开面板 → 用文字指挥 AI 帮你改图、画图、查数据。AI 由本软件内置驱动，只需配置一次你自己的模型 API Key，无需安装任何编程环境。

一、安装（4 步）

第 1 步：解压
把压缩包解压到任意目录（建议路径不含中文，例如 D:\new-acad-release）。
第 2 步：运行安装脚本
双击 install.bat（推荐，自动绕过执行策略），或右键 install.ps1 → 选择「使用 PowerShell 运行」。
看到 结果: N/通过 0/失败 0/警告 即安装成功。
如仍被拦截，手动执行： 
Set-ExecutionPolicy Bypass -Scope Process
第 3 步：打开 Civil 3D 并配置 AI
正常启动 C3D，插件自动加载。命令行输入 HANK_SHOW 调出面板。
面板顶部是模型配置区： 
选择模型 [服务商下拉] [模型下拉]
[API Key 输入] [显示]
[操作上限 20] [保存]
① 选服务商（DeepSeek / OpenAI / 通义 / Kimi / 智谱 / MiniMax / OpenRouter / xAI / 自定义）
② 选模型
③ 填你的 API Key（点"显示"可看明文；以后只改其他配置无需重填）
④ 操作上限：AI 单次任务自动执行的步数上限，默认 20；填 0 表示不限（AI 连续执行直到任务完成，可随时点「取消任务」停止）。点输入框会弹说明气泡
⑤ 点保存——立即生效，无需重启
保存后状态栏显示 ● 在线 | llm/服务商/模型 | CAD 即配置完成。
第 4 步：开始使用
在面板下方输入框打字 → 回车发送 → AI 操作 CAD → 结果回面板。
API Key 说明：Key 只保存在本机 config.json，不会上传任何服务器，也不会随软件分发。更换模型随时回面板顶部改。

二、日常使用

面板操作流程

在 CAD 里框选图元 → 切到面板 → 打字发消息 → AI 操作 CAD → 结果回面板

面板按钮

输入框下方一行：发送 / 取消任务 / 清理会话 / 更多清理；状态栏右侧是重启服务。

按钮作用
发送发送输入框内容（回车也可发送）
取消任务取消排队中/处理中的 AI 任务（结果不再回显，AI 停止响应本次请求）
清理会话清空当前对话与消息队列（AI 短期记忆重置；长期记忆不受影响）
更多清理打开清理菜单：清理日志 / 清理缓存文件 / 清理 MISSING 报告 / 全部清理。只清运行产生的临时文件，长期记忆（AI 记住的规则偏好）永远不在清理范围内，你导出的报告/数据文件也永远不会被清理
重启服务状态栏右侧：relay 掉线/异常时一键重启（自动拉起守护进程，约 3~5 秒自动恢复）
输入栏：支持多行自动换行；拖动输入区上方的分隔条可自由调整输入栏高度。

操作示例

你在面板里说AI 会做
"选中图元变成红色"改颜色（1=红）
"我选了什么东西"读类型、图层、属性
"在 0,0 画根 2000 的线"画线
"画个 100×50×30 的盒子"创建 3D 实体
"帮我算曲面面积"查询曲面数据
"这两个实体合并"3D 布尔并集
"帮我看 D:\xx.png 里有什么"读取图片并查看（需模型支持视觉，如 gpt-4o / qwen-vl；不支持时会提示换模型）

AI 能力边界

内置 AI 通过受控接口操作 CAD，安全边界（2026-08-13 版）：
读：AI 能读你明确指定的本地文件（文本/CSV/Word/Excel/PPT/压缩包/图纸，看文件夹清单）——敏感文件自动拦截（配置文件/密钥/凭据类，如 config.json、.env），读到的内容会发送给 AI 模型服务商处理
写：AI 只能新建文件（需你明确指定保存位置），不能修改/覆盖/删除你的已有文件；可执行/脚本文件（.exe/.bat/.ps1 等）一律禁写
遇到软件不支持的指令，AI 会明确回复 [MISSING] 功能缺失说明，不会瞎编或乱操作。

项目文件夹（可选，多工程管理）

按工程隔离数据：如果你同时做好几个工程（路桥/管网/市政...），可以给每个工程建一个项目文件夹，AI 在这个工程里的临时文件、选择记忆互不串。 
配置区最下面一行「项目名」：
- 下拉选已有项目 = 直接切换（点一下就过去）
- 输新名字 + 点「建立」 = 新建项目文件夹并切换
- 「打开」 = 在资源管理器里看这个项目的文件夹
- 「清理」 = 删掉这个项目的全部数据（确认后不可恢复）
- 不填 = 全局模式，所有图纸数据放一起（和以前一样）
适合场景：以项目为单位干活时用（比如“甲路项目”“乙桥项目”）；随手画小图不填也行。

AI 记忆（长期记忆）

AI 有长期记忆（保存在 server\memory\agent-memory.md，重启软件不丢）： 
"记住：我习惯用米制单位"
"以后出图默认比例 1:500"
"算量前先跟我确认范围线"
记忆只存规则、偏好、方法；具体任务和图纸数据不会写入（防污染）。点"清理会话"只清当前对话，不影响长期记忆。

本地文件读写（导出报告 / 读取数据）

AI 可以帮你新建文件到任意指定位置——导出报告、生成数据文件（CSV/JSON/文本等，格式不限）： 
"把曲面体积报告导出到桌面"
"生成桩号数据 CSV 到 D:\报告\"
"读一下这个文件的内容"
"看看 D:\xx文件夹 里有什么"
AI 能读取的文件：文本（txt/csv/json）、Word（docx）、Excel（xlsx）、PPT（pptx）、压缩包（zip 看清单）、CAD 图纸（自动打开查看）——老版 .doc/.xls/扫描版 PDF 读不了，让 AI 引导你转格式即可。
安全红线（保护你的数据）：
- AI 只能新建文件——已存在的文件不允许修改/覆盖（防止误覆盖重要数据）
- AI 不能删除你的任何文件——删除文件需你手动操作
- 敏感文件读不了：配置文件/密钥/凭据类（config.json、.env、证书等）自动拦截
- 可执行/脚本文件（.exe/.bat/.ps1 等）一律禁写
- 读到的文件内容会发送给 AI 模型服务商处理，敏感数据请自行斟酌 - 如需更新已有文件内容：让 AI 新建一个新文件（如 xxx_v2.csv），原文件保持不变

大数据量任务怎么用（批量 / 文件通道）

处理大量图元或大数据文件（几百上千个点、整图层批量改、CSV 导入等）时，你不需要任何特殊操作——AI 会自动走高效通道，不再一个一个慢慢处理： 
"把这 2000 个点全部加到曲面"
"把 D:\data\points.csv 里的点导入 Cogo"
"选中图层 0 的所有图元改成红色"
"把我选中的东西导出成 JSON 文件"
AI 自动判断的规则：
① 批量优先——复数对象用批量方法（一次处理 N 个），禁止逐个调用
② 文件通道——数据量 >500 条自动改走文件导入/导出（任意文本格式都能读，AI 自己判断分隔符/列序）
③ 先出计划——大规模任务（选中 ≥20 个或含"批量/csv/大量"等词）AI 会先告诉你"用什么方式、预计几轮完成"，再动手
④ 中途预警——处理轮数过多时 AI 会主动提示改走批量方式
⑤ 方法清单自动缓存——AI 首次查询方法清单后缓存 5 分钟，之后秒回，不再反复扫描

五、常见问题

现象解决
面板不显示C3D 命令行输 HANK_SHOW
面板显示"未配置 AI"面板顶部选服务商/模型 → 填 API Key → 保存
面板显示"离线"双击 server\start-relay.bat，或重跑 install.ps1
AI 说"连接不到 CAD"确认 C3D 已打开、插件已加载（命令行输入 C3DMCPSTATUS 查看）
选中图元但 AI 读不到发消息时面板已自动捕获选择集；仍读不到 → 先按 ESC 取消选择，重新框选后再发消息
AI 回复 [MISSING]该功能暂不支持——如实报告，不会瞎操作；可反馈给软件作者安排开发
复杂任务 AI 处理超时复杂任务（算量/曲面/批量修改）耗时较长属正常；频繁超时可在 config.json 的 llm 段调大 timeoutMs（默认 120000 毫秒）后重启 relay
relay 服务异常/面板离线点面板状态栏右侧「重启服务」一键修复；或双击 server\start-relay.bat。relay 由守护启动器托管：崩溃自动重启（连崩 5 次冷却 60 秒防死循环）；排查看 server\relay-launcher.log（守护）和 server\relay-crash.log（崩溃原因）
保存模型后没反应确认 Key 正确；换服务商后需重新保存（服务商切换时模型列表会刷新）
AI 能改/删我的文件吗？不能。AI 只能新建文件（导出报告/数据），不能修改或删除已有文件——安全红线，防误覆盖
导出的文件去哪了？AI 会回复文件完整路径（你说放哪就放哪，如桌面/指定文件夹），按路径去取即可
C3D 崩溃重启 C3D 自动恢复；插件会在启动时重新加载

六、日志与卸载

日志位置

插件日志: %LOCALAPPDATA%\Civil3DMcpPlugin\plugin.log
中转日志: 解压目录\server\relay.log
守护日志: 解压目录\server\relay-launcher.log（relay 启动/崩溃自动重启记录）
崩溃兜底: 解压目录\server\relay-crash.log（未捕获异常落盘，供排查）
AI 记忆:  解压目录\server\memory\agent-memory.md（长期记忆，可手动编辑）

卸载

一键卸载: 运行解压目录下的 uninstall.ps1（自动移除自动加载/自启/进程/运行态）

或手动:
1. 删除解压目录
2. 删除 %APPDATA%\Autodesk\C3D <年份>\chs\Support\ 下的 acad.lsp 和 Hank.lsp
3. 删除计划任务 AcBridge-Relay（Win+R 输入 taskschd.msc → 任务计划程序库）

七、技术构成与运行环境

重要：最终用户无需安装任何编程环境。运行时只有两样——本包自带的 node.exe + 你本来就有的 Civil 3D。
语言在项目里的角色你需要做什么
C# (.NET 8)CAD 插件核心（数百个操作方法，数量以软件内清单为准）什么都不用做（C3D 自动加载，自带运行库）
JavaScript (Node.js)AI 通信桥 / MCP 服务器 / 面板中转什么都不用做（包内已带 node.exe）
PowerShell安装脚本 install.ps1 / 卸载脚本 uninstall.ps1右键运行一次（Windows 自带）
AutoLISP启动时自动加载插件什么都不用做（C3D 原生支持）

运行环境要求

操作系统: Windows 10 / 11
CAD 软件: Civil 3D 2024 / 2025 / 2026（自动检测版本）
模型 API: 任一 OpenAI 兼容服务商的 Key（面板内配置）
无需: Node.js / Python / .NET SDK / 任何编程环境
