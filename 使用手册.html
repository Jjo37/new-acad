🖥️ new-acad 使用手册

版本 v1.4.2 ｜ 让 AI 直接帮你操作 AutoCAD / Civil 3D

这不是"给 AI 套一层 CAD 工具"。new-acad 是装在 CAD 里的内置 AI 工程助手：大脑（AI 判断逻辑）内置在软件里，不依赖任何外部平台——不用注册我们的账号、不用装其他客户端，你只需要填一个自己的模型 API Key。
一句话说明：在 Civil 3D 里选中图元 → 打开面板 → 用文字指挥 AI 帮你改图、画图、查数据。AI 由本软件内置驱动，只需配置一次你自己的模型 API Key，无需安装任何编程环境。

一、安装（4 步）

第 1 步：解压
把压缩包解压到任意目录（建议路径不含中文，例如 D:\new-acad-release）。
第 2 步：运行安装脚本
双击 install.bat（推荐，自动绕过执行策略），或右键 install.ps1 → 选择「使用 PowerShell 运行」。
看到 结果: N/通过 0/失败 0/警告 即安装成功。
如仍被拦截，手动执行： 
Set-ExecutionPolicy Bypass -Scope Process
第 3 步：打开 Civil 3D 并配置 AI
正常启动 C3D，插件自动加载。命令行输入 HANK_SHOW 调出面板。
面板顶部是模型配置区： 
选择模型 [服务商下拉] [模型下拉]
[API Key 输入] [显示]
[操作上限 20] [保存]
① 选服务商（DeepSeek / OpenAI / 通义 / Kimi / 智谱 / MiniMax / OpenRouter / xAI / 自定义）
② 选模型
③ 填你的 API Key（点"显示"可看明文；以后只改其他配置无需重填）
④ 操作上限：AI 单次任务自动执行的步数上限，默认 20；填 0 表示不限（AI 连续执行直到任务完成，可随时点「取消任务」停止）。点输入框会弹说明气泡
⑤ 界面语言：自动（跟随系统）/ 中文 / English —— 选中立即切换并记住
⑥ 点保存——立即生效，无需重启
保存后状态栏显示 ● 在线 | llm/服务商/模型 | CAD 即配置完成。
第 4 步：开始使用
在面板下方输入框打字 → 回车发送 → AI 操作 CAD → 结果回面板。
API Key 说明：Key 只保存在本机 config.json，不会上传任何服务器，也不会随软件分发。更换模型随时回面板顶部改。

二、日常使用

面板操作流程

在 CAD 里框选图元 → 切到面板 → 打字发消息 → AI 操作 CAD → 结果回面板

面板按钮

输入框下方一行：发送 / 取消任务 / 清理会话 / 更多清理；状态栏右侧是重启服务。配置区（点状态栏最右 ▼ 展开）里有界面语言下拉。

按钮作用
发送发送输入框内容（回车也可发送）
取消任务取消排队中/处理中的 AI 任务（结果不再回显，AI 停止响应本次请求）
清理会话清空当前对话与消息队列（AI 短期记忆重置；长期记忆不受影响）
更多清理打开清理菜单：清理日志 / 清理缓存文件 / 清理 MISSING 报告 / 全部清理。只清运行产生的临时文件，长期记忆（AI 记住的规则偏好）永远不在清理范围内，你导出的报告/数据文件也永远不会被清理
重启服务状态栏右侧：relay 掉线/异常时一键重启（自动拉起守护进程，约 3~5 秒自动恢复）
界面语言配置区下拉（自动（跟随系统）/ 中文 / English）：切换面板与端口诊断对话框的语言。选中立即生效并记住，下次打开仍是该语言
界面语言：安装向导选「English」装出来就是英文界面（选中文同理）；装完也能随时用配置区的 界面语言 下拉切换，选择保存在 config.json 的 locale（auto = 跟随系统）。
实时进度：状态栏会实时显示 AI 当前在做什么（推送，不是定时刷新）；任务结束自动回落。
输入栏：支持多行自动换行；拖动输入区上方的分隔条可自由调整输入栏高度。

操作示例

你在面板里说AI 会做
"选中图元变成红色"改颜色（1=红）
"我选了什么东西"读类型、图层、属性
"在 0,0 画根 2000 的线"画线
"画个 100×50×30 的盒子"创建 3D 实体
"帮我算曲面面积"查询曲面数据

"帮我看 D:\xx.png 里有什么"读取图片并查看（需模型支持视觉，如 gpt-4o / qwen-vl；不支持时会提示换模型）

AI 是怎么"想"的（决策链）

内置 AI 不是把几百个 CAD 方法一股脑丢给模型让它猜，而是有一套工程判断（这也是本软件和别家最大的不同）： 
① 先查再调   不确定方法名 → 先查软件内实时方法清单，禁止瞎猜
② 识别规模   命中"算量/曲面/廊道/批量/报告"或选中≥20个 → 先给你 1-2 行计划
③ 选通道     单个 → 直接调 ｜ 多个同类 → 批量一次处理 N 个
             ｜ 数据 >500 条 → 走文件通道 ｜ 重操作 → 后台任务排队（不卡界面）
④ 遇阻不硬撞 主程序忙/后台任务占用 → 不反复重试同一方法，改走别的路子或问你
⑤ 诚实边界   同一方法失败 3 次 → 停手；做不到就明说，不瞎操作
对用户的意义：你只管说要什么，通道怎么走由它判断——大批量任务不会一个个磨，长任务不会卡死界面。

AI 能力边界

内置 AI 通过受控接口操作 CAD，安全边界（2026-08-13 版）：
读：AI 能读你明确指定的本地文件（文本/CSV/Word/Excel/PPT/压缩包/图纸，看文件夹清单）——敏感文件自动拦截（配置文件/密钥/凭据类，如 config.json、.env），读到的内容会发送给 AI 模型服务商处理
写：AI 只能新建文件（需你明确指定保存位置），不能修改/覆盖/删除你的已有文件；可执行/脚本文件（.exe/.bat/.ps1 等）一律禁写
遇到软件不支持的指令，AI 会明确回复 [MISSING] 功能缺失说明，不会瞎编或乱操作。

项目文件夹（可选，多工程管理）

按工程隔离数据：如果你同时做好几个工程（路桥/管网/市政...），可以给每个工程建一个项目文件夹，AI 在这个工程里的临时文件、选择记忆互不串。 
配置区「项目名」一行：
- 下拉选已有项目 = 直接切换（点一下就过去）
- 输新名字 + 点「建立」 = 新建项目文件夹并切换
- 「打开」 = 在资源管理器里看这个项目的文件夹
- 「清理」 = 删掉这个项目的全部数据（确认后不可恢复）
- 不填 = 全局模式，所有图纸数据放一起（和以前一样）
适合场景：以项目为单位干活时用（比如"甲路项目""乙桥项目"）；随手画小图不填也行。

AI 记忆（长期记忆）

AI 有长期记忆（保存在 server\memory\agent-memory.md，重启软件不丢）： 
"记住：我习惯用米制单位"
"以后出图默认比例 1:500"
"算量前先跟我确认范围线"
记忆只存规则、偏好、方法；具体任务和图纸数据不会写入（防污染）。点"清理会话"只清当前对话，不影响长期记忆。

本地文件读写（导出报告 / 读取数据）

AI 可以帮你新建文件到任意指定位置——导出报告、生成数据文件（CSV/JSON/文本等，格式不限）： 
"把曲面体积报告导出到桌面"
"生成桩号数据 CSV 到 D:\报告\"
"读一下这个文件的内容"
"看看 D:\xx文件夹 里有什么"
AI 能读取的文件：文本（txt/csv/json）、Word（docx）、Excel（xlsx）、PPT（pptx）、压缩包（zip 看清单）、CAD 图纸（自动打开查看）——老版 .doc/.xls/扫描版 PDF 读不了，让 AI 引导你转格式即可。
安全红线（保护你的数据）：
- AI 只能新建文件——已存在的文件不允许修改/覆盖（防止误覆盖重要数据）
- AI 不能删除你的任何文件——删除文件需你手动操作
- 敏感文件读不了：配置文件/密钥/凭据类（config.json、.env、证书等）自动拦截
- 可执行/脚本文件（.exe/.bat/.ps1 等）一律禁写
- 读到的文件内容会发送给 AI 模型服务商处理，敏感数据请自行斟酌
- 如需更新已有文件内容：让 AI 新建一个新文件（如 xxx_v2.csv），原文件保持不变

大数据量任务怎么用（批量 / 文件通道）

处理大量图元或大数据文件（几百上千个点、整图层批量改、CSV 导入等）时，你不需要任何特殊操作——AI 会自动走高效通道，不再一个一个慢慢处理： 
"把这 2000 个点全部加到曲面"
"把 D:\data\points.csv 里的点导入 Cogo"
"选中图层 0 的所有图元改成红色"
"把我选中的东西导出成 JSON 文件"
AI 自动判断的规则：
① 批量优先——复数对象用批量方法（一次处理 N 个），禁止逐个调用
② 文件通道——数据量 >500 条自动改走文件导入/导出（任意文本格式都能读，AI 自己判断分隔符/列序）
③ 先出计划——大规模任务（选中 ≥20 个或含"批量/csv/大量"等词）AI 会先告诉你"用什么方式、预计几轮完成"，再动手
④ 后台任务——耗时长的重操作（廊道重建等）自动排队执行，不占用界面、不撞超时
⑤ 方法清单自动缓存——AI 首次查询方法清单后缓存 5 分钟，之后秒回，不再反复扫描

🖥️ new-acad User Guide

Version v1.4.2 ｜ Let an AI drive AutoCAD / Civil 3D for you

This is not "an AI wrapped around some CAD tools". new-acad is a built-in AI engineering assistant living inside CAD: the brain (the AI's judgement logic) ships inside the software and depends on no external platform — no account with us, no extra client to install. You only bring your own model API key.
In one sentence: select entities in Civil 3D → open the palette → type what you want and the AI edits, draws and queries for you. The AI is driven by this software itself; configure your own model API key once and you're set — no programming environment required.

1. Install (4 steps)

Step 1 — Unzip
Unzip the archive to any folder (avoid non-ASCII characters in the path, e.g. D:\new-acad-release).
Step 2 — Run the installer script
Double-click install.bat (recommended; it bypasses the execution policy), or right-click install.ps1 → "Run with PowerShell".
When you see 结果: N/通过 0/失败 0/警告 (N passed / 0 failed / 0 warnings) the install succeeded.
If it is still blocked, run this manually: 
Set-ExecutionPolicy Bypass -Scope Process
Step 3 — Open Civil 3D and configure the AI
Start Civil 3D normally; the plugin loads itself. Type HANK_SHOW on the command line to bring up the palette.
The top of the palette is the model config area: 
Provider [dropdown] [model dropdown]
[API Key input] [Show]
[Step limit 20] [Save]
① Pick a provider (DeepSeek / OpenAI / Qwen / Kimi / Zhipu / MiniMax / OpenRouter / xAI / custom)
② Pick a model
③ Paste your API key ("Show" reveals it; later changes to other settings don't require re-entering it)
④ Step limit: how many actions the AI may take per task, default 20; enter 0 for unlimited (it keeps going until done — hit "Cancel task" any time). Hovering the box shows a tooltip.
⑤ Language: Automatic (follow system) / 中文 / English — takes effect and is remembered immediately
⑥ Click Save — effective immediately, no restart.
The status bar then reads ● Online | llm/provider/model | CAD.
Step 4 — Start using it
Type in the input box at the bottom → press Enter → the AI operates CAD → the result comes back to the palette.
About the API key: the key is stored only in the local config.json. It is never uploaded to any server and never shipped with the software. Change the model any time at the top of the palette.

2. Daily use

Typical flow

Select entities in CAD → switch to the palette → type your message → AI operates CAD → result comes back

Palette buttons

Below the input box: Send / Cancel task / Clear chat / More; on the right of the status bar: Restart. The config area (expand it with ▼ at the far right of the status bar) holds the Language dropdown.

ButtonWhat it does
SendSends the input box contents (Enter works too)
Cancel taskCancels a queued/running AI task (its result is discarded; the AI stops working on this request)

How the AI thinks (the decision chain)

The built-in AI does not get handed hundreds of CAD methods to guess from. It comes with engineering judgement — and this is the biggest difference from other approaches: 
1. Look up first   unsure of a method name → query the live method list; never guess
2. Spot the scale  complex keywords or ≥20 selected → print a 1-2 line plan first
3. Pick a channel  single → direct ｜ many of a kind → batch, N at once
                   ｜ >500 records → file channel ｜ heavy op → background job (no UI freeze)
4. Do not ram      CAD busy / job running → no repeated retries of the same method;
                   take another route or ask you
5. Honest boundary 3 failures of a method → stop; if it cannot do it, it says so
What it means for you: you just say what you want — the AI decides how to route it. Large batches stop grinding one by one, and long operations don't freeze the UI.

What the AI may and may not do

The AI works through controlled interfaces (safety model as of 2026-08-13):
Read: it can read local files you explicitly point it to (text/CSV/Word/Excel/PPT/archives/drawings, and list folders) — sensitive files are blocked (config/key/credential files such as config.json or .env). Content it reads is sent to your AI model provider for processing.
Write: it can only create new files (you must specify where), and cannot modify, overwrite or delete existing files. Executable/script files (.exe/.bat/.ps1 …) can never be written.
If something is not supported it replies with an explicit [MISSING] note instead of improvising.

Project folders (optional — multi-project isolation)

Keep data per project. If you run several projects (roads/bridges/utilities…), give each one a project folder so the AI's temp files and selection memory never bleed across. 
Config-area "Project" row:
- pick an existing project from the dropdown = switch to it
- type a new name + "Create" = make the folder and switch
- "Open" = reveal the project folder in Explorer
- "Clear" = delete all data of that project (irreversible after confirming)
- leave empty = global mode, everything shares one workspace (as before)
When to use it: when you work project by project. For quick one-off drawings, leaving it empty is fine.

AI memory (long-term)

The AI has long-term memory (stored in server\memory\agent-memory.md; survives restarts): 
"remember: I work in metric units"
"default plot scale 1:500 from now on"
"confirm the boundary with me before quantity takeoff"
It stores rules, preferences and methods only — never task or drawing data (to avoid pollution). "Clear chat" only clears the current conversation; long-term memory is unaffected.

Reading and writing local files

The AI can create files wherever you tell it to — reports, data files (CSV/JSON/text, any format): 
"export the surface volume report to my desktop"
"write a CSV of the station data to D:\reports\"
"read this file and summarise it"
"what's in the folder D:\xx?"
Formats it can read: text (txt/csv/json), Word (docx), Excel (xlsx), PowerPoint (pptx), archives (zip listings), CAD drawings (opens and inspects them). Legacy .doc/.xls and scanned PDFs are not supported — it will guide you to convert.
Safety red lines (protecting your data):
- The AI can only create files — existing files are never modified or overwritten
- The AI cannot delete any of your files — you do that yourself
- Sensitive files are unreadable: config/key/credential files (config.json, .env, certificates…) are blocked
- Executable/script files (.exe/.bat/.ps1 …) can never be written
- Content it reads is sent to your AI model provider — judge accordingly for sensitive data
- To update an existing file, have the AI create a new one (e.g. xxx_v2.csv) and keep the original intact

Large tasks (batching and the file channel)

For large entity sets or big data files (thousands of points, whole-layer edits, CSV imports…) you don't need to do anything special — the AI automatically takes the efficient route instead of grinding one by one: 
"add these 2000 points to the surface"
"import the points in D:\data\points.csv into Cogo"
"make every entity on layer 0 red"
"export my selection to a JSON file"
Rules the AI applies by itself:
① Batch first — batch methods and array parameters for many objects; calling one by one is forbidden
② File channel — above ~500 records it switches to file import/export (any text format; it figures out the delimiter and column order)
③ Plan first — for big tasks (≥20 selected, or words like "batch"/"csv"/"lots of") it states the approach and expected number of steps before starting
④ Background jobs — long operations (corridor rebuilds etc.) queue up without holding the UI or hitting timeouts
⑤ Method list caching — the method list is cached for 5 minutes after the first query, so later lookups are instant
